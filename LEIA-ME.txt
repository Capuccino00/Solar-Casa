SOLAR CASA — ATUALIZAÇÃO DE HISTÓRICO E ANÁLISES

Esta versão deixa a análise histórica mais visível na página inicial e mostra explicitamente os 208 registros diários e as faturas históricas que já estão embutidos no aplicativo. Não é necessário cadastrar as 208 entradas manualmente.

ARQUIVOS
- index.html
- sw.js
- manifest.webmanifest

PUBLICAÇÃO
1. Faça backup da planilha Google Sheets e exporte um backup JSON pelo app.
2. Extraia este ZIP.
3. No repositório GitHub Solar-Casa, substitua index.html e sw.js pelos arquivos deste pacote. O manifest.webmanifest é incluído para manter o pacote completo; pode ser substituído também.
4. Faça commit na branch main e aguarde o GitHub Pages publicar.
5. Abra https://capuccino00.github.io/Solar-Casa/ e atualize com Ctrl+F5. O cache do app foi atualizado para v4.

NOTAS
- O histórico do Excel é embutido para consulta e análise; não precisa ser copiado para as abas de dados novos do Google Sheets.
- Os rótulos dos ciclos foram preservados porque os anos/datas completas não são inequívocos no Excel.
- Faça backup antes de testar; a sincronização do Google Sheets pode reescrever as abas de dados do aplicativo.
